# Security policy

## Supported versions

The latest release and the default branch receive security fixes.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature for this repository. If it is unavailable,
contact the maintainers privately using the address listed in the repository profile. Do not open a
public issue until a fix is available.

Include the affected version, impact, reproduction steps, and a proposed mitigation if known. Remove
API keys, tunnel URLs, Hugging Face tokens, uploaded document content, and personal information.

You should receive acknowledgement within seven days. This is a volunteer project and cannot promise
a remediation date, but reports will be triaged by severity.
