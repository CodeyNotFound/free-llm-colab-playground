# SillyTavern

SillyTavern menus can change, so use its current official documentation for exact labels.

1. Start the model and create the temporary API tunnel.
2. Open SillyTavern's API connection settings.
3. Choose an OpenAI-compatible/custom OpenAI connection.
4. Paste the playground **Base URL** (including `/v1`).
5. Paste the generated **API key**.
6. Fetch/select the exact **Model ID** shown by the playground.
7. Disable streaming when connecting through Cloudflare Quick Tunnel.
8. Connect and send a short test message.

Never save or share the temporary key in a public configuration. See the
[SillyTavern documentation](https://docs.sillytavern.app/usage/api-connections/).
